I'm a BCA Cybersecurity graduate interested in penetration testing, system security, and understanding how vulnerabilities work.

I use hands-on labs, controlled experiments, and technical investigations to develop practical skills. I enjoy going beyond running tools — understanding the underlying mechanisms, reproducing issues, analyzing evidence, and documenting fixes.
